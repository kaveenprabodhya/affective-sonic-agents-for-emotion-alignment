Which estimator is which

Estimator A coach models/estimator_A2

Guides the optimisation loop. It scores every candidate, reports the gap to the target back to the language model, and decides when the loop stops. It sees everything, so agreeing with it is not evidence that a logo carries the intended emotion.

Estimator B held out models/estimator_B2

An additional held-out judge, chosen by the architecture comparison in models/selection/. Never consulted during generation.

A trailing 2 marks an estimator chosen by the architecture Coach and judge are trained on different corpora and are never the same model, so agreement between them carries information. Where an estimator was replaced during the study, only the one actually used is shown; the filename beside each name above is the artefact it came from. First candidate is iteration 0 of a run, before any revision; best candidate is the best the loop found within its iteration cap. Both come from the same run and the same brief.

Reading the plots

Valence runs left to right, arousal bottom to top. The dashed ring is where the brief aimed. The hollow dot is the first candidate, the filled dot is the best one the optimiser found, and the line between them is how far it travelled. Every plot shares one scale, ±0.80 of the ±1 circumplex, so a judge whose dots barely move really is barely moving. No point is ever clipped, and the numbers under each plot are the coordinates being drawn, so the picture can be checked against the CSV. The quadrant badge on each card reports Estimator A's verdict, since that is the estimator the stopping rule could act on; a held-out judge may place the same stimulus on the other side of an axis.
