Which estimator is which

Estimator A coach models/estimator_A2

Guides the optimisation loop. It scores every candidate, reports the gap to the target back to the language model, and decides when the loop stops. It sees everything, so agreeing with it is not evidence that a logo carries the intended emotion.

Estimator B held out models/estimator_B2

An additional held-out judge, chosen by the architecture comparison in models/selection/. Never consulted during generation.

Coach and judge are trained on different corpora and are never the same model, so agreement between them carries information. Where an estimator was replaced during the study, only the one actually used is shown; the filename beside each name above is the artefact it came from. First candidate is iteration 0 of a run, before any revision; best candidate is the best the loop found within its iteration cap. Each brief has three independent generation runs.

Reading the plots

Valence runs left to right, arousal bottom to top. The dashed ring is where the brief aimed. The hollow dot is the first candidate, the filled dot is the best candidate, and the line between them is how far it travelled. Every plot shares one scale, ±1.10 of the ±1 circumplex, so a judge whose dots barely move really is barely moving. No point is clipped, and the numbers beneath each plot are the coordinates being drawn. The quadrant badge inside a run reports Estimator A's verdict because that estimator controlled the stopping rule; a held-out judge may place the same stimulus differently.
